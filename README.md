## Реализованные API для дополнительной функциональности `rating_events`

### 1. Приватный контроллер (`PrivateRatingController`)

| Метод  | Адрес запроса                            | Описание                                           |
|--------|------------------------------------------|----------------------------------------------------|
| POST   | `/{userId}/ratings/{eventId}/{reaction}` | Поставить реакцию (лайк/дизлайк) событию           |
| DELETE | `/{userId}/ratings/{eventId}/{reaction}` | Удалить ранее поставленную реакцию                 |
| GET    | `/{userId}/ratings`                      | Получить список понравившихся пользователю событий |

### 2. Административный контроллер (`AdminRatingController`)

| Метод | Адрес запроса              | Описание                                                                                               |
|-------|----------------------------|--------------------------------------------------------------------------------------------------------|
| GET   | `/admin/ratings/by-events` | Получить пользователей, поставивших указанную реакцию (лайк/дизлайк) для одного или нескольких событий |
| GET   | `/admin/ratings/by-users`  | Получить статистику реакций (лайков и дизлайков) для заданных пользователей                            |

### 3. Публичный контроллер (`PublicRatingController`)

| Метод | Адрес запроса | Описание                                                                              |
|-------|---------------|---------------------------------------------------------------------------------------|
| GET   | `/ratings`    | Получить рейтинг событий с возможностью указания размера выборки и порядка сортировки |
